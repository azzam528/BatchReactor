Model Information

Informasi model machine learning dan simulation yang digunakan pada Batch Reactor Intelligence.

Supervised Learning

Random Forest Regressor

Digunakan untuk memprediksi temperatur reactor pada timestep berikutnya berdasarkan kondisi reactor saat ini.

Input Features
  • Reactor Temperature
  • Jacket Flow Rate
  • Pressure
  • Reactant A Concentration
  • Product B Concentration
Prediction Target

Reactor Temperature T(t+1)

Monitoring

Prediction error dihitung dari perbedaan antara actual T(t+1) dan predicted T(t+1) ketika nilai actual tersedia.

Reinforcement Learning

RL Simulation

Digunakan untuk memberikan rekomendasi tindakan jacket flow berdasarkan kondisi reactor dalam simulation environment.

State

State dapat menggunakan lima parameter reactor:

  • Reactor Temperature
  • Jacket Flow Rate
  • Pressure
  • Reactant A Concentration
  • Product B Concentration
Candidate Actions
Action ID Action
0 Decrease Jacket Flow
1 Maintain Jacket Flow
2 Increase Jacket Flow
Simulation only: rekomendasi RL digunakan sebagai decision support dalam simulation environment, bukan instruksi kontrol otomatis terhadap reactor fisik.
Prediction & Monitoring Flow
Step 1
Current Reactor State

Lima parameter kondisi reactor digunakan sebagai input model.

Step 2
Temperature Prediction

Model memprediksi temperatur pada timestep berikutnya.

Step 3
Prediction Error

Prediksi dibandingkan dengan actual T(t+1) ketika tersedia.

Step 4
RL Simulation

Agent memberikan rekomendasi action dalam simulation environment.

Model Artifacts

Artifact model akan digunakan oleh backend setelah pipeline training selesai.

System Purpose

Sistem ini digunakan sebagai Batch Reactor Prediction, Monitoring & RL Simulation Dashboard. Sistem memprediksi temperatur timestep berikutnya, memonitor prediction deviation, dan menyediakan rekomendasi tindakan melalui simulation environment. Sistem ini merupakan decision-support system dan bukan physical reactor controller.
